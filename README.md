# Ping Pong Game (Arduino C/C++)

This project is a simple **Ping Pong game** written in **C/C++ for Arduino**.  
Run it on Arduino (simulated) and play directly in your browser.

## 🎮 Try it on Wokwi
Open the project link below, press the **Play (▶)** button, and enjoy:

- Wokwi Demo: https://wokwi.com/projects/428854153411798017

## ✨ Features
- Classic ping pong gameplay
- Runs on Arduino using embedded C/C++
- Easy to test and play using the Wokwi simulator

## ▶ How to Run
1. Open the Wokwi link above  
2. Click **Play (▶)**  
3. Start playing!

## 📌 Notes
If you want to run it on real hardware, make sure your Arduino wiring matches the project setup in Wokwi.
